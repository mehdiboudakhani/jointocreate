# 🤖 JoinToCreate
Eliminate voice channel clutter with JoinToCreate.

## 🔍 Overview
JoinToCreate is a public Discord bot built with **Discord.Net** that dynamically creates temporary voice channels. This approach prevents voice channel clutter on Discord servers.

## ❓ How it works
It's very simple! The bot has only one command: `/new-hub`. Server administrators can use this command to create hubs. When a user joins a hub, the bot creates a temporary voice channel for them. Once the temporary voice channel becomes empty, it is automatically deleted.

The `/new-hub` command offers three options:
- `child-name` sets the name for the temporary voice channels.
- `user-limit` sets a maximum number of users allowed in temporary voice channels.
- `interface` allows temporary voice channel owners to manage their own channels.
